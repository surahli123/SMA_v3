Enterprise Experiment Post-Analysis Data Agent

Architecture overview Draft

Read-only evidence flows from production authorities (laptop entitlement under D8, or a P2 source later) and fixtures, through a capability boundary, into an append-only workspace. A deterministic evaluator seals an immutable packet labeled with its evidence class and authorization scope. Humans review the digest; only the Experiment Review Committee rules. Diagnostic Trace is a separate, untrusted store.

Trust boundaries

Three zones, one direction

  • Production authorities and fixtures enter only through the Capability Broker (P2 gates real sources).
  • Inside the Agent, every record is append-only and digest-chained.
  • Humans act on the sealed digest; the Committee ruling is external.
  • Program M0 capability demonstrated and per-Flight analysis_use are separate fields (S13); the first needs one real Flight under a laptop-scoped receipt (D8) plus independent adjudication.

What the evaluator does

Deterministic, fail-closed

  • 19 checks; preregistered sufficiency (D1), arm parity (D2), union-metric registration (S3).
  • One stored state, analysis_use; eligibility is a projection (D3).
  • Recomputation carries an independence class and a shared-snapshot Coverage Gap (D4/D6).
  • Fixed core plus Flight-specific checks are sealed before outcome reads (S11).

Trace

Separate and untrusted

  • Cross-linked to receipts; never supports or contradicts.
  • Not part of the packet digest; a separately versioned annex.
  • Missing optional Trace is a Coverage Gap, not a blocker.
