## Open-Gate Meaning

The terminal reviewer may assess whether each open gate is correctly specified, fail-closed, evidence-backed, and impossible to bypass. The reviewer must not mark a gate closed, invent production facts or numeric thresholds, substitute advisor opinion for named-human authority, or turn absent evidence into a negative finding.

The permitted sequence for evaluation is:

```text
prepared threshold-free contract
  -> sealed authorization for one evaluation rung
  -> authorized evidence collection while the evaluation ticket remains open
  -> complete receipts and adjudication for the applicable closure checklist
  -> named-human closure of the evaluation ticket
  -> Scenario A production GO evaluation
```

Production-like replay additionally requires production-authority closure and explicit Engineering plus security/privacy authorization. Shadow-read requires its own named scope, isolation, retention/redaction, load, stop, and exit authorization.
