## 1. How to Read This Matrix

- `complete`: the named research, decision, specification, or planning deliverable exists and current authoritative evidence covers its stated requirement.
- `open gate`: the contract or preparation asset exists, but named human or pilot evidence required for acceptance is missing.
- `historical review`: a review is complete for its exact historical bytes but its verdict does not transfer to later revisions.
- `unresolved by design`: a source conflict or value must remain unknown until stronger evidence or a named pilot resolves it.

Artifact completion is not production readiness. A canonical specification can be complete while production authority, interaction acceptance, evaluation calibration, and production GO remain open.
