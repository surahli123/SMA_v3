# Owner-Selected Design Contract

PROTOTYPE / THROWAWAY. This iteration treats the two owner-selected screens and the four route references derived from them as the primary visual and interaction contract.

## Shared language extracted from the owner-selected screens

- A compact dark identity block anchors an otherwise light forensic workspace.
- A stable case rail, top route navigation, central task workspace, and persistent right inspector create one predictable review geometry.
- Thin rules and aligned rows carry hierarchy. Elevation is reserved for a selected record or permission boundary.
- Orange identifies selection, contradiction, and blocked state. Green is reserved for validated records. Neither color is decorative.
- Technical sans carries navigation and explanation; monospace carries identifiers, timestamps, locators, receipts, code, and raw output.
- Tables, code, graph paths, and provenance are primary. Narrative explains authority boundaries but never replaces proof.

## Route mapping

| Route | Primary review question | Reference-derived composition |
|---|---|---|
| Review | What is the current conclusion, and what most strongly supports or contradicts it? | Case rail; conclusion authority strip; ruled 2x2 evidence matrix; Case Facts inspector; persistent Proof Dock. |
| Claims | Which competing claim best explains the miss, and where is the conflict? | Competing-claims rail; typed horizontal graph with grouped bands; controls and legend; persistent Evidence Inspector. |
| Verify | What exact deployed code and artifact were observed, and how does the unapplied candidate differ? | Evidence path; deployed authority strip; side-by-side code; literal `not_applied`; Receipts and Provenance inspector. |
| Trace | What ran, in what order, and which events cross-link to validated Evidence? | Explicit not-Evidence boundary; filters; dense event table and state path; raw-output inspector; linked-evidence return path. |

## Product-fit precedence

Marketing AIDA, hero/footer composition, conversion CTAs, stock imagery, GSAP scroll choreography, and perpetual motion were not applied. They conflict with a high-stakes, dependency-free investigation workspace. The named taste skills materially changed typography discipline, accent restraint, hierarchy, spacing, anti-card rules, focus feedback, responsive behavior, and the removal of ornamental UI. The image-to-code phase treats route references as composition contracts rather than optional inspiration.
