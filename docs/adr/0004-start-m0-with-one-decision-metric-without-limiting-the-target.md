# Start M0 with one decision metric without limiting the target

The target product policy allows one Flight to have multiple co-primary decision metrics governed by a frozen, predeclared combination and conflict rule. The first M0 slice starts with one decision metric by default and admits co-primary only as an explicitly approved exception. Contracts and packet schemas must therefore model a decision-metric set plus its policy rather than encode singular cardinality as a permanent invariant; the first M0 acceptance slice may exercise only the single-metric case.
