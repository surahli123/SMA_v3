# Run M0 through M2 as one active-time-bounded validation slice

The first implementation program targets one authorized production Flight running end to end through M0 Flight Readiness, M1 Metric Movement and Production Grounding, and M2 Win/Loss Evidence in four to six active engineering weeks with two full-time builders and part-time domain, DS, review, and security support. M0 remains the first gate and main deliverable, but M1 and M2 are implemented in this validation slice rather than left direction-only. The primary builder's August 24 through September 14 leave is excluded from active engineering time; a reproducible continuity checkpoint is due before leave so another builder can continue or the primary builder can resume within half a day. End of September is a stretch target, and technical completion means review-ready packets, not Experiment Review Committee acceptance.
